# Benchmark status

No comparison was collected before the architecture was superseded by the user's 2026-09-23 clarification. Startup, idle RAM/CPU, process counts, scroll performance, minimized CPU and voice CPU remain **not measured** for a valid matched comparison.

The external harness and optional in-app recorder are source artifacts from the prior WebView2 prototype. They do not establish that the new requested architecture exists or performs better. See [the revised direction](DIRECTION_NATIVE_FR.md).
